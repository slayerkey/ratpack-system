ONE TIME SETUP

Connect Claude Code

Auto Queue uses Claude Code's supported hooks to identify the active chat and hand off queued work. Open Setup, click Connect Claude Code once, then use Claude normally.

Target Chat

Auto follows the Claude chat you used most recently. Choose a chat only when you want this key permanently bound to one session.

Queue Prompt

Pressing this key saves the request locally. Claude receives it after the current turn finishes. Maximum 9,000 characters.

Queue Control

Local by design

Queued prompts stay on this computer. PackRat does not read or modify Claude credentials and does not upload your prompts.
