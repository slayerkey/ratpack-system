Auto Queue for Claude Code

Queue a follow-up now. It waits until Claude finishes the message it is already working on, then becomes the next request in that same chat.

ONE TIME SETUP

Connect, then send one normal message

1. Open Setup and click Connect Claude Code. 2. Send one normal message in the Claude chat you want to use. That first real message lets PackRat learn which chat is active. 3. While Claude is working, press a Queue Prompt key. It does not send immediately. 4. When Claude finishes the current turn, your queued prompt becomes the next request in the same chat.

Target Chat

Auto follows the last Claude chat that sent a normal user message after setup. If Auto is waiting for a chat, send one normal message in the Claude chat you want, then queue your follow-up. Choose a specific chat only when you want this key bound to that session.

Queue Prompt

Pressing this key only queues the request. It does not interrupt Claude or type into VS Code. Claude receives it after the current turn finishes. Maximum 9,000 characters.

Queue Control

Local by design

Queued prompts stay on this computer. PackRat does not read or modify Claude credentials and does not upload your prompts.
