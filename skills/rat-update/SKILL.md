# Rat Update

Read the published product state, current marketplace version, changelog, support signals, and requested change.

Define the scope, update version metadata, implement through the normal product type build workflow, update release notes, rerun art only when marketplace presentation changes, run full QA, and then route to Rat Ship.

Do not rename immutable published identifiers.
