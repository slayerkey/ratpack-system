ENTRY SYNTAX

[ ] Task
Creates a tappable checklist item.

[x] Task
Creates a checklist item that starts checked.

Blank Entry
Starts another note card.

Plain text
Creates a normal note line.

ON XENEON EDGE

Tap a checklist item to mark it complete or incomplete.

SETTINGS

Note Settings contains the note theme, font size, text color, accent color, background color and transparency controls in one iCUE group.
