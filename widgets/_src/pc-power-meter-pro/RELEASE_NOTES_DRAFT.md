# PC Power Meter Pro Release Notes Draft

Initial Pro release with a primary measured iCUE power sensor, separate comparison sensors, multi-line rolling graph, integrated session and daily energy, configurable electricity cost, local session history, configurable graph windows, high-power threshold, explicit measurement scope, strict disconnect and reconnect continuity, and all eight XENEON layouts.

No CPU plus GPU sum is presented as total PC power. Idle versus active classification is intentionally omitted in V1 because the current sensor contract does not provide a universal workload-state signal.
