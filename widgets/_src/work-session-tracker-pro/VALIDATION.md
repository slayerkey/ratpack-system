# Validation contract

Release candidate requires:

1. Canonical source flattening with `tools/xeneon/inline.py`.
2. Official `icuewidget-cli@0.4.47 validate` and package on Windows CI.
3. Packaged behavioral QA, including all eight XENEON slot sizes.
4. StreamSpell packaged preview validation at all eight sizes.
5. Deterministic Rat Art captures and marketplace media contract.
6. Rat Ship Maker Console SHIP_KIT preflight.

Timer state is timestamp-segment based. No correctness claim depends on a setInterval counter.
