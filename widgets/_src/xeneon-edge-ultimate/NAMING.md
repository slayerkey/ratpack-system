# XENEON EDGE Ultimate naming decision

## Working storefront title

`XENEON EDGE Ultimate`

## Why this is the current lead

The product is one integrated `.icuewidget`, not a literal set of separately installed widgets. `Ultimate` communicates the definitive whole-device upgrade without narrowing the product to monitoring or implying that the user must assemble a bundle.

## Shortlist

1. XENEON EDGE Ultimate
2. Ultimate XENEON EDGE Bundle
3. PackRat XENEON EDGE Ultimate
4. XENEON EDGE Ultimate Suite
5. XENEON EDGE Ultimate Dashboard

## Recommendation

Keep the package ID and slug as `xeneon-edge-ultimate` regardless of the final Marketplace title. If market testing strongly favors the explicit bundle wording, change only `manifest.json` / `submission.json` display naming before 1.0.0.

## Positioning line

`Your XENEON EDGE, all in one.`

## Supporting claim

`One finished dashboard for performance, weather, media, schedule, focus and connection health.`
