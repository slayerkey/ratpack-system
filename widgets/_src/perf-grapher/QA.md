## Customer feedback already present in recovered 1.4.0

The recovered source already contains the requested Sensor Readout Size slider, Performance Header Size slider, optional HTTPS response-time display, and the unit-safe split value/unit markup. 1.4.1 preserves these features and adds regression coverage around them.

## 1.4.1 transparency recovery

The prior panel token was `rgba(255,255,255,0.045)`. It only looked dark because an opaque body existed below it. When body transparency became active after an iCUE dashboard page transition, the wallpaper showed directly through the sensor panels and cells.

1.4.1 makes the panel surface an opaque color derived from the selected background while leaving the outer widget background alpha user-controlled. `applyBackgroundPaint()` is the single owner of background alpha. Visibility/page restoration explicitly reapplies current personalization without multiplying or compounding opacity.

## Additional hardening

* iCUE property reads use the canonical `__ratpackIcueRead` direct-binding bridge generated by `tools/xeneon/inline.py`, with a normal window fallback for compatibility runners.
* Top-right sensor readouts can shrink within the card while keeping the unit fixed inside its bounds. This directly protects the intermittent `°C` clipping case with FPS disabled.
* Ping uses the same file-origin-safe opaque HTTPS timing model already proven by Network Dashboard and requests one byte from Cloudflare instead of a zero-byte path.
