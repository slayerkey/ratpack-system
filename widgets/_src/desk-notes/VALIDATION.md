# Desk Notes Lite validation

## Verdict
BUILD. This is a strong XENEON-native utility because the product solves a persistent-screen problem rather than duplicating a desktop app window.

## Feasibility
- Official iCUE `textfield` controls are used for title and note entry. No unsupported keyboard capture is required.
- Official local storage guidance supports per-widget persistence keyed by `uniqueId`.
- The official Link Provider is used only for the optional Pro discovery overlay.
- No API, account, cloud backend, helper app, or secret is required.

## Lite product boundary
Lite remains permanently useful: one board, eight entries, mixed plain/checklist lines, touch completion, title, six themes, font sizing, local persistence, and eight-slot support.

## Upgrade boundary
Pro adds repeat-use organization: multiple boards, more entries, multiple note cards, categories, pinning, history, rotation, arrangement options, and additional presentation choices. Lite does not lose any core reminder workflow.

## Marketplace rule check
Current Marketplace product guidelines explicitly recommend free Lite / paid variants and prohibit external paywalls or third-party payment redirects. The upgrade path therefore targets only the Elgato Marketplace listing through iCUE Link Provider.
