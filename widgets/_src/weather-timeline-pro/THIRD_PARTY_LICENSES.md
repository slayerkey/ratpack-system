# Third Party Data / Licenses

Weather data is fetched at runtime. No third-party art, icon set, font, or code library is bundled in this product. Weather condition icons are original inline SVG paths authored for this widget.

Potential runtime providers:

* Open-Meteo commercial customer API when an iCUE-provided customer credential is available. Open-Meteo weather data requires attribution under CC BY 4.0; the provider name is shown in the widget status area and Marketplace copy should retain provider attribution where required.
* WeatherAPI.com when the user supplies their own API key. Use is subject to the user's WeatherAPI account terms.
