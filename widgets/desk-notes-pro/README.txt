DESK NOTES PRO — QUICK GUIDE

Edit each board title and Entry field in iCUE widget settings. Pro includes four boards, 16 Entry fields per board, board rotation, multiple layouts and local completed history.

ENTRY SYNTAX

[ ] Task
Creates a tappable checklist item.

[x] Task
Creates a checklist item that starts checked.

! [ ] Task
Pins the item to the top of its card.

Blank Entry
Starts another note card.

## Heading
Adds a heading to the current note card.

# Category
Adds a category label to the current note card.

Plain text
Creates a normal note line.

ON XENEON EDGE

Tap a checklist item to mark it complete or incomplete.
Tap a board tab to switch boards manually.
When Rotate Boards is enabled, boards advance automatically after the configured interval. Manual board selection pauses rotation temporarily.
Completed checklist items can be viewed from the history button when Completed History is enabled.

SETTINGS

Board Settings contains arrangement, rotation, history, note theme, font size and Custom Style controls in one iCUE group so the controls remain reachable on the iCUE settings screen.
