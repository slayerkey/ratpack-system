Pro Provider API Setup

Leetify powers Premier and Competitive stats. FACEIT powers FACEIT stats only. Each provider uses your own free key, so another user's usage cannot consume your allowance.

Leetify · Premier & Competitive
API key required

Unlocks: Premier Rating, Competitive map ranks, recent Competitive result, win rate, and Leetify Rating.

  1. Sign in to Leetify.
  2. Open the Developer API page.
  3. Copy your API key and paste it below.

Your Steam and CS2 data must already be connected in Leetify for Valve rank data to exist.

FACEIT · FACEIT Stats
API key required

Unlocks: FACEIT Elo, Level, Region, K/D, HS%, win rate, recent record, and recent match.

  1. Sign in to the FACEIT Developer Portal.
  2. Create an App in App Studio.
  3. Open API Keys and create a Client Side key.
  4. Copy the key and paste it below.

FACEIT may require account verification or two-step verification depending on your account. Those requirements come from FACEIT, not PackRat.

Add the Leetify key for Competitive stats, the FACEIT key for FACEIT stats, or both.

Keys are stored in this plugin's local Stream Deck settings on this PC and sent only to the matching provider API. They are never sent to a PackRat server.
