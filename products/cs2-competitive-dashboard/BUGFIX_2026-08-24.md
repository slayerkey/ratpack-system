# CS2 Competitive Dashboard live host bugfix pass

Date: 2026-08-24

> **Historical record only.** The manual Enable/Disable workflow documented below was superseded by the later deep host debugging pass in `HOST_DEBUG_GSI_2026-08-24.md`. Current builds start local GSI automatically and do not use an Enable button. Use `QA.md` for the current Windows host gate.

Observed on a real Windows Stream Deck host after `rat dev cs2-competitive-dashboard`:

## First host pass

* Property Inspector controls appeared interactive but Enable Live CS2 Tracking, Save Steam Profile, Refresh Stats, and per-action metric changes produced no visible result.
* Steam profile text did not visibly persist after reopening the Property Inspector.
* Session Metric stayed on the default session record after selecting K/D, ADR, HS%, or matches.
* The customer-facing `DERIVED` label on ADR and HS% was confusing implementation language.
* CS2 was already running during setup, but the UI did not explain that a newly installed GSI config requires one CS2 restart before the game loads it.

Fix contract:

* load `pi.js` synchronously so `connectElgatoStreamDeckSocket` exists before Stream Deck attempts PI registration
* make PI WebSocket registration explicit, reconnectable, and visible to the user
* disable plugin command controls while the PI is disconnected instead of silently swallowing clicks
* queue a bounded number of commands while reconnecting
* request settings and runtime status after registration
* add an executable mocked-WebSocket regression test for register -> getSettings -> get-status ordering
* save Steam profile/provider-key global settings before starting asynchronous provider refreshes
* detect an already-running `cs2.exe` during runtime initialization
* expose `gsiRestartRequired` and show Restart CS2 once when setup happens while CS2 is running
* clear restart-required state as soon as the first valid GSI payload arrives
* make session metric choices render as distinct zero-state values before the first tracked match
* remove customer-facing `DERIVED` wording from ADR and headshot percentage

## Second host pass

The PI connection fix worked and bundled profiles were proven to import manually. New issues found:

* bundled profiles do not auto-install during `streamdeck link` development mode even though the packaged plugin and profile manifests pass Elgato validation
* manually double-clicking the generated `.streamDeckProfile` succeeds, confirming the profile format itself is valid
* Enable Live CS2 Tracking now visibly receives the click but can remain stuck on `Enabling live tracking...`
* Disable can similarly remain stuck on `Disabling...`
* live tracking setup does not explain the full GSI lifecycle clearly enough for a first-time user
* provider setup does not make it obvious enough that Leetify powers Premier/Competitive data while FACEIT only powers FACEIT data

Second-pass fix contract:

* give PI commands a 12-second watchdog so the UI can never remain in a pending state forever
* give runtime PI operations a 10-second timeout and return explicit success/error command results
* make GSI server shutdown close idle/all local HTTP connections after a short grace period so Disable cannot wait forever on a stale keep-alive connection
* explain live tracking as Enable once -> write local Valve GSI config -> restart CS2 once if already open -> enter a game mode -> Connected to CS2 after first payload
* state explicitly that live/session tracking needs no provider API key
* label Leetify as `Premier & Competitive` and list the exact metric family it unlocks
* label FACEIT as `FACEIT Stats` and list the exact metric family it unlocks
* add an `Open bundled profile files` fallback in the PI for hosts where bundled profile auto-install did not run
* keep packaged profile registration because normal plugin installation can still use the supported bundled-profile lifecycle

Manual validation after updating through Rat Dev:

1. Open any CS2 action and confirm the PI top strip says `Property Inspector connected`.
2. Change Session Metric from Session Record to K/D and confirm the key immediately changes to `SESSION K/D 0.00` before gameplay.
3. Paste a Steam profile, press Save Steam Profile, close and reopen the action, and confirm the profile remains populated.
4. Press `Open bundled profile files` and confirm Explorer opens the Pro profile folder. Double-click the profile for the current device if it is not already installed.
5. With CS2 already open, press Enable Live CS2 Tracking and confirm the pending state resolves within 12 seconds.
6. If setup succeeds while CS2 is open, confirm the PI says `GSI installed · restart CS2 once`.
7. Restart CS2, enter Deathmatch or another normal game mode, and confirm status changes to `Connected to CS2` and Live/Session keys begin updating.
8. Press Disable and confirm it resolves to a disabled state instead of remaining on `Disabling...`.
9. Confirm the provider cards explicitly identify Leetify as the Premier/Competitive source and FACEIT as the FACEIT-only source.
